# 03 — Downstream analysis

This area generates the PBMC/K562-r joint and K562-r-only embeddings and
compares bulk K562-R versus K562-S differential expression with single-cell
effects. The manuscript signature selects 50 genes per direction, 100 total,
and also defines the descriptive resistance module score.

## Inputs and outputs

- Embedding inputs: PBMC count matrix, K562-r Seurat object, and explicit fusion
  candidate table.
- Embedding outputs: joint and K562-r-only Seurat objects, UMAP coordinate
  tables, and figures.
- Concordance inputs: raw bulk integer-count matrix, bulk sample metadata, and
  the single-cell Seurat object.
- Concordance outputs: edgeR tables, selected signature, single-cell effect
  tables, concordance metrics/figures, and per-cell resistance scores.

Exact manuscript signature ranking uses the archived production bulk-DE table
through `BULK_DE_TABLE`. The raw-count edgeR run remains available as a
sensitivity analysis but is not assumed to reproduce a table generated by a
different edgeR release. Production defaults are FDR < 0.05, |log2FC| >= 1,
mitochondrial/ribosomal-prefix exclusion, 50 genes per direction, and
`AddModuleScore(ctrl=50, nbin=24, seed=20260729)`.

## Run

```bash
cp config/embedding.example.sh config/embedding.sh
cp config/embedding_inputs.example.tsv config/embedding_inputs.tsv
bash code/run_embedding.sh config/embedding.sh

cp config/concordance.example.sh config/concordance.sh
cp config/bulk_samples.example.tsv config/bulk_samples.tsv
# Supply the bulk count matrix and edit the config.
bash code/run_concordance.sh config/concordance.sh
```

For the study data, start from `config/concordance.study.example.sh`; it fixes
the recovered production direction, signature filters, and module-score values
while leaving only the archived input paths to fill.

`code/run_all.sh` can sequence any configured subset of all three repository
areas. Correlations and module scores are descriptive; relevant statistical
limitations are documented in [`../docs/methods.md`](../docs/methods.md).
